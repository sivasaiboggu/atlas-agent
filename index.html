          Settings

          Replies come from Google Gemini. Paste your own free API key — it is stored only in this browser, never sent anywhere except to Google's API.

          Get a free key at Google AI Studio. If the key is wrong, the app says so plainly instead of inventing an answer.

          If a model is unavailable for your key, the error from Google is shown as-is.

          Data

          A backup holds chats, tasks, notes, reminders and plans. It never includes your API key.

          Restoring replaces everything currently in Atlas. Reminders only fire while Atlas is open in a tab — a page cannot wake itself.

          About this app. Atlas is a general-purpose everyday agent: job search, mail, web research, tasks, notes, files, planning — anything you ask it to do. It works by calling real tools in this browser and answering from what they return. It never invents a fact, a link, or a sent mail.

          Tools it can use: web search, reading pages, weather, tasks, notes, mail drafts, arithmetic, reading attached files.

          Nothing you type leaves this browser except the messages you send to Google Gemini, using your key. Chats, tasks and notes live in this browser's local storage. Erasing them removes them for good.

          What Atlas cannot do. It cannot send mail by itself — drafts open in Gmail for you to send. It cannot drive other websites or your browser; a page can only read what sites allow it to read. Some pages block cross-origin reads, and Atlas says so instead of guessing.
